# Project Instructions

## Project

This repository contains my personal developer portfolio website.

## Goal

Build a clean, responsive, and professional portfolio that presents my software development, web development, AI/ML, Generative AI, and DSA work.

## Development Principles

- Keep the code simple and readable.
- Prefer maintainable solutions over unnecessary complexity.
- Keep the website responsive.
- Follow accessibility best practices.
- Do not expose API keys or secrets.
- Do not add unnecessary dependencies.
- Keep the project structure organized.
- Test changes before considering them complete.
- Explain important changes clearly.

## Git Guidelines

Use Conventional Commits.

Examples:

- `feat: add project section`
- `fix: improve mobile layout`
- `docs: update README`
- `chore: update configuration`
- `style: improve portfolio design`

## AI Assistant Guidelines

Before making significant changes:

1. Understand the existing code.
2. Explain what will be changed.
3. Make the smallest reasonable change.
4. Avoid changing unrelated files.
5. Check that the project still works after the change.

## Project Workflow

When working on this project:

1. Review the existing implementation before making changes.
2. Keep changes focused on the requested task.
3. Avoid modifying unrelated files.
4. Run the application after significant changes.
5. Verify that the UI works as expected.
6. Use clear Conventional Commit messages for Git changes.
